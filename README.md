## About me

I'm **Abdul Agantal Omar**, also known as **Aziz**. I build web and mobile applications that connect users, records, and everyday operations across education, agriculture, local government, and business.

My main stack is **Python, Flask, Jinja2, and JavaScript** for web applications, alongside **React Native, Expo, and TypeScript** for mobile development. I work with **SQLite and PostgreSQL**, including Neon, and build interfaces that adapt to desktop and mobile screens.

I enjoy turning requirements into complete workflows: an application becomes an approved record, a purchase moves through inventory and delivery, or an offline scan reaches the server with a clear confirmation. I care about clear responsibilities, useful interfaces, and preserving existing data as a system grows.

## What I bring to a project

- **Connected workflows:** I design how records move from submission and review through approval, fulfillment, or release.
- **Clear role ownership:** I build permissions and workspaces around the responsibilities of each user.
- **Practical interface design:** I work on readable dashboards, useful feedback, and forms that remain usable on smaller screens.
- **Reliable mobile behavior:** I handle offline records, retries, duplicate prevention, and visible synchronization states.
- **Careful database changes:** I work with migrations and import tools that preserve existing records and relationships.
- **Verification and documentation:** I check permissions and workflow behavior, document setup, and distinguish local validation from deployment results.
